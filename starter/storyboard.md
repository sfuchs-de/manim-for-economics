# General timed storyboard

Use this only when neither specialized project template captures the paper's
logic. Target one learning goal per beat and a 60–90 second first cut.

| Time | Learning goal | On-screen words | Visual action | Conceptual handoff | Evidence/status |
|---|---|---|---|---|---|
| 0–6 s | State the question | One short question | Introduce the recurring research object | The question identifies what must be explained | Abstract or introduction |
| 6–18 s | Define the object | Plain-language labels | Reveal only the parts needed later | Preserve the object across subsequent beats | Model, design, or measurement section |
| 18–32 s | Explain the central argument | Two or three mechanism words | Change the persistent object rather than replacing the stage | The change predicts the result to inspect | Theory, design, or institutional setting |
| 32–48 s | Show the result | One result sentence | Use the result's native form: chart, table, construction, or theorem | The result supplies the interpretation | Figure, table, proposition, or released data |
| 48–64 s | Interpret | Words first; notation only if useful | Reconnect the result to the active argument | The interpretation answers the opening question | Supported interpretation |
| 64–72 s | Close | One takeaway | Return to the opening object in its changed state | End on the contribution | Supported synthesis |

Before implementation, verify that every factual row has a source and that
illustrative visuals are explicitly labeled. Then add at least one named
`settled` frame per beat and one named `transition` frame per major handoff to
`project.toml`.
