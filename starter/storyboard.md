# Timed storyboard

Target one learning goal per beat. A useful first cut is 60–90 seconds.

| Time | Learning goal | On-screen words | Visual action | Conceptual handoff | Evidence/status |
|---|---|---|---|---|---|
| 0–5 s | State the question | One short question | Introduce the recurring object | The question identifies the agent or system to build | Paper abstract |
| 5–15 s | Situate the agent | Name choices in words | Reveal one margin at a time | Preserve these margins as later outcomes | Model section |
| 15–30 s | Explain identification | Name shock and outcome | Build the empirical comparison | The shock identifies responses along the same margins | Empirical section |
| 30–45 s | Show the result | One result sentence | Directly labeled chart | The estimated responses become interpretation inputs | Figure or table |
| 45–60 s | Interpret welfare | First order, then second order | Highlight the matching margins | Reuse the terms in the final takeaway | Theory + estimates |
| 60–70 s | Close | One takeaway | Return to the opening object | Answer the opening question | Supported synthesis |

Before implementation, verify that every factual row has a source and that
illustrative visuals are explicitly labeled. Then add at least one named
`settled` frame per beat and one named `transition` frame per major handoff to
`project.toml`.
