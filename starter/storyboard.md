# Timed storyboard

Target one learning goal per beat. A useful first cut is 60–90 seconds.

| Time | Learning goal | On-screen words | Visual action | Evidence |
|---|---|---|---|---|
| 0–5 s | State the question | One short question | Introduce the recurring object | Paper abstract |
| 5–15 s | Situate the agent | Name choices in words | Reveal one margin at a time | Model section |
| 15–30 s | Explain identification | Name shock and outcome | Build the empirical comparison | Empirical section |
| 30–45 s | Show the result | One result sentence | Directly labeled chart | Figure or table |
| 45–60 s | Interpret welfare | First order, then second order | Highlight the matching margins | Theory + estimates |
| 60–70 s | Close | One takeaway | Return to the opening object | Supported synthesis |

Before implementation, verify that every factual row has a source and that
illustrative visuals are explicitly labeled.
