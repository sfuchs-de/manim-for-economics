# Network policy ladder example

This complete synthetic example combines the package's location-first map, synchronized policy ladder, and selected-observation biography. It is the shortest end-to-end reference for adapting those patterns to a new spatial application.

Render and inspect it from the repository root:

```bash
uv run econ-manim preview examples/network_policy_ladder --overlay --no-cache
uv run econ-manim frames examples/network_policy_ladder --transition-sweep
uv run econ-manim qa examples/network_policy_ladder
```

Replace the CSV and GeoJSON together, preserve stable link identifiers, update `data_manifest.toml`, and keep every model state in one welfare unit.
