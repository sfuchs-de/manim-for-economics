# Manim for Economics v0.2.0

Version 0.2.0 turns the starter into a browsable scene library while keeping
the workflow paper-agnostic.

## What is new

- Four atomic recipes for path flows, channel decompositions, coefficient
  intervals, and impulse responses.
- Public `PathFlow`, `ChannelDecomposition`, and `CoefficientPlot` components.
- Confidence bands, explicit horizons, and event-time markers in
  `ImpulseResponsePlot`.
- Complete empirical-result-led and method-theory projects alongside the
  existing general, mechanism-led, and agent-choice-welfare starters.
- `econ-manim scenes`, `preview-scene`, and `add-scene` for browsing and
  copying recipes.
- `econ-manim frames PROJECT --transition-sweep` for five samples around every
  declared transition.
- Stronger `econ-manim qa` checks for inspection coverage, media profiles,
  decoding, checksums, and unexpected audio.

## Compatibility

Existing component signatures and template commands continue to work. The
package supports Python 3.11+; the recommended setup remains Python 3.12 with
Manim Community 0.20.1. Version 0.2.0 adds no runtime dependency.

## Illustrative-data policy

Every value in a generic recipe or paper template is illustrative and recorded
in its local data manifest. The generic library contains no paper-specific
estimate. Actual results must be copied from a released source, classified as
actual, attributed, checksummed, and cross-checked against the paper and
replication files.

See the [changelog](../../CHANGELOG.md), [scene catalog](../scene-catalog.md),
and [practitioner’s guide](../practitioners-guide.md) for details.
