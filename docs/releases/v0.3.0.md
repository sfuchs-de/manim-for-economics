# Manim for Economics v0.3.0

Version 0.3.0 turns the reusable patterns developed for a network-welfare
explainer into package-level data contracts, composite recipes, and a complete
synthetic workflow.

## What is new

- `SpatialStateDataset` validates the stable identifiers, state values, link
  geometry, labels, and units shared by linked empirical views.
- `LinkedEmpiricalViews` updates a geographic network map, an evolving scatter,
  and selected-rank histories together.
- New recipes stage a spatial policy ladder, follow one selected observation,
  and derive an adjoint from an equilibrium residual one step at a time.
- The synthetic network-policy example demonstrates the complete map-to-result
  workflow without external data.
- Cue-driven narration helpers and `narration-check` test script coverage,
  durations, recording files, and speaking rates.
- Built wheels now include the starter and copyable templates. Continuous
  integration tests project creation and recipe copying outside the checkout.

## Compatibility

Existing components, project templates, scene recipes, and command names remain
supported. The package continues to require Python 3.11 or newer and Manim
Community 0.20.1. No runtime dependency was added.

## Data policy

The new composite recipes and network-policy example use small, deterministic,
illustrative inputs with local provenance manifests. Paper-specific empirical
results remain outside generic templates.

See the [changelog](../../CHANGELOG.md), [scene catalog](../scene-catalog.md),
and [linked empirical views guide](../linked-empirical-views.md) for details.
