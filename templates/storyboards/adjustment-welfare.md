# Adjustment-and-welfare storyboard template

Use this when the paper connects an agent's responses to welfare or policy
measurement.

| Time | Learning goal | On-screen words | Visual action | Conceptual handoff | Evidence/status |
|---|---|---|---|---|---|
| 0:00–0:07 | Make heterogeneity concrete | Why does the same shock affect [agent/group] differently? | Compare two symmetric states with one controlled difference | The comparison identifies the margin of heterogeneity | Mechanism |
| 0:07–0:20 | Define the agent and menu | [choice 1], [choice 2], [choice 3] | Reveal each route from the same origin | The routes become both outcomes and welfare inputs | Dynamic problem |
| 0:20–0:30 | Explain the economic state variable | [concentration, access, liquidity, exposure] in words | Apply the same shock under two menus | The state variable predicts different adjustment | Theory |
| 0:30–0:42 | Introduce identifying variation | [exposure] × [aggregate shock] | Move from the schematic agent to the released empirical object | The variation identifies responses along the same routes | Design + manifest |
| 0:42–0:55 | Show response heterogeneity | One result sentence | Draw directly labeled response paths | The estimated flows are inputs to welfare | Published figure or table |
| 0:55–1:12 | Build the welfare statistic | direct response + curvature/insurance | Add one word-equation term while activating its routes | The decomposition now has an economic interpretation | Theory + estimates |
| 1:12–1:24 | Report and interpret welfare | for whom · which shocks · relative to what | Show the compact result and return to the opening comparison | Close on the supported mechanism | Published welfare result |

Before coding:

- State the welfare baseline, sample, dates, horizon, discounting, and units.
- Keep positive and negative realizations separate when the paper evaluates them
  separately.
- Use the same route labels in the agent view, response charts, and welfare
  build.
- Add named settled and transition frames to `project.toml`.
