# Method-or-theory storyboard template

Use this when the contribution is a theorem, estimator, sufficient statistic,
algorithm, identification result, or model solution.

| Time | Learning goal | On-screen words | Visual action | Conceptual handoff | Evidence/status |
|---|---|---|---|---|---|
| 0:00–0:06 | State the problem | What is hard to measure, identify, or solve? | Show one recurring mathematical or economic object | The limitation motivates the operation | Introduction |
| 0:06–0:19 | Define the object | Inputs and target in words | Build only notation that will be used | The viewer can now follow transformations | Definitions |
| 0:19–0:34 | Show the key operation | condition, transformation, or restriction | Change the object one step at a time | The operation produces the result | Method or proof |
| 0:34–0:49 | State the result | Theorem or estimator in words | Complete the construction before revealing formal notation | The result resolves the opening problem | Proposition |
| 0:49–1:03 | Give intuition | one comparative static or counterexample | Change one assumption while holding geometry fixed | The contrast explains why conditions matter | Corollary or example |
| 1:03–1:16 | Connect to use | what becomes estimable, computable, or interpretable | Show the output in an application-shaped view | The abstract result gains purpose | Application |
| 1:16–1:24 | Close | One contribution sentence | Return to the original object in solved form | Answer the opening problem | Synthesis |

Use equations only when each symbol has already acquired meaning. If the proof
itself is not the contribution, animate the economic operation rather than
typesetting the proof.
