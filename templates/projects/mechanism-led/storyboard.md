# Mechanism-led timed storyboard

| Time | Learning goal | On-screen words | Visual action | Conceptual handoff | Evidence/status |
|---|---|---|---|---|---|
| 0:00–0:06 | Pose the system-wide question | How does [change] affect [outcome]? | Show a short causal chain | The question identifies the system to build | Motivation |
| 0:06–0:22 | Build the baseline system | Direct labels for essential objects | Add only economically necessary nodes, markets, or constraints | The completed system defines the baseline | Model or setting; label schematic geometry |
| 0:22–0:32 | Introduce one change | [change] in words | Modify one persistent object; do not reset the stage | The change initiates the routes that follow | Policy, shock, or comparative static |
| 0:32–0:48 | Trace propagation | [channel 1], [channel 2], [channel 3] | Activate one route at a time | Preserve channel labels for the comparison | Mechanism |
| 0:48–1:04 | Compare cases | Relative to [benchmark] | Grow directly labeled results from a fixed zero line | Sign and magnitude reveal which channels matter | Table, figure, or simulation |
| 1:04–1:16 | Synthesize | [outcome] = [channels] | Reuse the preserved words in an incremental expression | Return to the opening question | Supported interpretation |

Add a named settled frame for each beat and a transition frame for each major
handoff. Do not code until the intervention, channels, and benchmark are
unambiguous.
