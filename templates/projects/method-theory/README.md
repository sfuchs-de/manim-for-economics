# Method- or theory-led template

Use this project when the contribution is a theorem, estimator, sufficient
statistic, algorithm, identification result, or model solution.

The persistent object is the mathematical or economic object transformed by
the method. The starter introduces it in words, applies one operation, states
the result, changes one condition, and connects the output to an application.

The bundled comparative-static values are illustrative. Replace them with a
proved or documented comparison, or remove the numeric panel.

```bash
uv run econ-manim preview templates/projects/method-theory --overlay
uv run econ-manim frames templates/projects/method-theory
uv run econ-manim qa templates/projects/method-theory
```
