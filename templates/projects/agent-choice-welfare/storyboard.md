# Agent-choice-welfare timed storyboard

| Time | Learning goal | On-screen words | Visual action | Conceptual handoff | Evidence/status |
|---|---|---|---|---|---|
| 0:00–0:07 | Define the decision problem | [choice 1], [choice 2], [choice 3] | Reveal each alternative from one origin | Preserve choices as later outcomes and welfare inputs | Model or institutional setting |
| 0:07–0:19 | Introduce the change | [shock, treatment, policy, or state] | Change payoffs or availability without moving the origin | The same agent now faces a different menu | Definition and baseline |
| 0:19–0:31 | Make heterogeneity concrete | [state with more options] vs [state with fewer options] | Compare controlled menus or constraints | The state predicts different responses | Mechanism |
| 0:31–0:46 | Introduce evidence | One identifying sentence | Move from schematic choices to the released empirical object | Evidence recovers or disciplines the same margins | Design + manifest |
| 0:46–1:00 | Show response heterogeneity | One result sentence | Draw directly labeled paths, estimates, or contrasts | Responses become interpretation inputs | Figure or table |
| 1:00–1:17 | Build welfare or policy value | direct payoff + value of responses | Add one word term while activating its choice margin | The decomposition now has economic intuition | Theory + evidence |
| 1:17–1:28 | Interpret | for whom · relative to what · over what horizon | Return to the changed choice menu | Answer the opening decision problem | Supported result |

If the paper does not make a welfare claim, rename the last two beats
“policy value,” “objective,” or the paper's actual interpretation. Do not force
a sufficient statistic onto a paper that does not have one.
