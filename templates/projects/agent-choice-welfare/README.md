# Agent-choice-welfare project template

Use this template when choices, adjustment, or heterogeneity connect to a
welfare or policy object. Its narrative grammar is informed by the
economic-diversity explainer, but the template is not tied to workers, cities,
or labor markets.

The recurring token may represent a household, firm, investor, student,
patient, platform, government, or other decision maker.

```bash
uv run econ-manim new my-paper --template agent-choice-welfare
uv run econ-manim preview projects/my-paper --overlay
```
